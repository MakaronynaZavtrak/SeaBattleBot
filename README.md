# SeaBattleBot 🚢

Telegram-бот «Морской бой»: игра один-на-один с расстановкой кораблей,
рейтингом, званиями и таблицей лидеров.

## Стек

- Java 21
- Spring Boot 4.1.0
- telegrambots 6.8 (long polling)
- PostgreSQL (JDBC)
- Google Guava (кэш пользователей)
- Maven

## Требования

- JDK 21+
- Maven 3.9+
- Работающий PostgreSQL с таблицей `users`

## Конфигурация

Секреты и параметры подключения не хранятся в репозитории — они читаются из
переменных окружения (см. `src/main/resources/application.yml`).

| Переменная            | Назначение                                   |
|-----------------------|----------------------------------------------|
| `BOT_NAME`            | @username бота                               |
| `BOT_TOKEN`           | токен от BotFather                           |
| `BOT_CREATOR_CHAT_ID` | chatId создателя (для сообщений об ошибках)  |
| `DB_URL`              | JDBC-строка, напр. `jdbc:postgresql://localhost:5432/seabattle` |
| `DB_USER`             | пользователь БД                              |
| `DB_PASSWORD`         | пароль БД                                    |
| `DB_DRIVER`           | опционально, по умолчанию `org.postgresql.Driver` |

Для локальной разработки удобно положить переменные в `.env` или в
`application-local.yml` (оба уже в `.gitignore`).

## Запуск

```bash
# сборка
mvn clean package

# запуск из исходников
mvn spring-boot:run

# либо собранный jar
java -jar target/sea-battle-bot-0.1.0.jar
```

## Дорожная карта

Проект проходит поэтапную модернизацию. Ветки именуются `stage_N_<название>`,
коммиты — по Conventional Commits (`type(scope): описание`).

| Этап | Тема                                          |
|------|-----------------------------------------------|
| 0    | Фундамент: Spring Boot, Java 21, логи, конфиг  |
| 1    | Тесты: характеризационная сетка               |
| 2    | Доменная модель: enum, Coord, без магии        |
| 3    | Рефакторинг God-класса                          |
| 4    | БД: пул соединений, оконные функции             |
| 5    | Виртуальные потоки, потокобезопасность          |
| 6    | Алгоритмы: расстановка, битборд                 |
| 7    | Миграция telegrambots 6.8 → 9.x                 |
| 8    | Docker, CI/CD                                   |
| 9    | Нативная компиляция (GraalVM)                   |
